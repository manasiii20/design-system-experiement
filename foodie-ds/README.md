# foodie-ds

Mobile-first design system for an Indian food delivery app. Vite + React + TypeScript,
plain CSS custom properties, Storybook. Designed for a 390px viewport.

```bash
npm install
npm run storybook   # component workshop on :6006
npm run dev         # app playground
```

- Tokens: `src/tokens/tokens.css`
- Rules for contributors (human or AI): [`CLAUDE.md`](./CLAUDE.md)
